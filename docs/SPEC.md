1. អត្តសញ្ញាណ និងគោលបំណង

Central Intelligence Data Core (CIDC) គឺជាមជ្ឈមណ្ឌលទិន្នន័យកណ្ដាលរបស់ KHOEM-AI ដែលត្រូវបង្កើតឡើងដើម្បីប្រមូល រៀបចំ រក្សាទុក គ្រប់គ្រង ផ្ទៀងផ្ទាត់ និងផ្ដល់ទិន្នន័យចំណេះដឹងពីវិស័យផ្សេងៗទៅឱ្យប្រព័ន្ធ AI/UI របស់ KHOEM-AI។

CIDC មិនមែនជាទំព័រទិន្នន័យតែមួយប្រភេទទេ។ វាជាប្រព័ន្ធទិន្នន័យកណ្ដាលធំមួយ ដែលមានទំព័ររង និងផ្នែកទិន្នន័យជាច្រើនតាមជំនាញ។

ទំព័ររងទាំងអស់មានឋានៈជាផ្នែករបស់ CIDC ហើយត្រូវប្រើគោលការណ៍គ្រប់គ្រងទិន្នន័យកណ្ដាលរួមគ្នា។

គោលដៅគឺបង្កើតមូលដ្ឋានទិន្នន័យដែលអាចពង្រីកបាន ដោយអាចបន្ថែមទំព័រទិន្នន័យ និងវិស័យចំណេះដឹងថ្មីៗបានជាបន្តបន្ទាប់។
